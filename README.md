# Ocean Depths

## Overview

Ocean Depths is an interactive storytelling website that explores the different layers of the ocean through immersive animations and scroll-based navigation. Users journey from the ocean surface to the deepest trenches while learning about marine ecosystems and ocean life.

## Live Demo

https://oceandepths.netlify.app/

## Features

- Interactive scroll-based storytelling
- Animated underwater environments
- Information about ocean depth zones
- Responsive design
- Smooth transitions and visual effects

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP

## Installation

1. Clone the repository.
2. Open `index.html` in your browser.
