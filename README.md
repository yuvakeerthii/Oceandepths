# Ocean Depths

## Overview

Ocean Depths is an interactive single-page web application that provides a cinematic exploration of the ocean's different depth zones. As users scroll through the page, they descend from the ocean surface to the Mariana Trench while experiencing smooth animations, visual storytelling, and informative content about marine life and ocean environments.

## Features

* Scroll-based storytelling experience
* Multiple ocean depth zones
* Animated marine life and underwater elements
* Smooth scrolling and transitions using GSAP
* Dynamic depth and temperature display
* Scroll progress indicator
* Loading screen animation
* Responsive design for desktop and mobile devices
* Modern UI with immersive visual effects

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* GSAP
* GSAP ScrollTrigger

## Installation

1. Clone the repository.

```bash
git clone https://github.com/krishna-vamshi-t/ocean-depths.git
```

2. Navigate to the project directory.

```bash
cd ocean-depths
```

3. Open `index.html` in any modern web browser.

No additional installation or dependencies are required.
